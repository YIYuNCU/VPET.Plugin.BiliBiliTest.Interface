# 常见问题

## 插件没有出现在列表里

先看主日志：`<游戏主目录>/ModData/BiliVpet/Log/Main/` 里最新的文件，搜“加载外部插件”。主日志可以在“日志工具”页看到；如果设置文件里把主日志关了（`Log` 节的 `Enable` 为 false），这里不会有记录。

按下面的顺序检查：

1. **位置不对**：dll 必须在 `<游戏主目录>/ModData/BiliVpet/SubPlugins/<插件名>/` 里。放在 `SubPlugins` 根目录、mod 的 `plugin` 文件夹或旧版本约定的 mod 目录下的 `Plugins`、`SubPlugins` 文件夹都不会加载。用设置窗口“基本设置”页的“打开子插件文件夹”按钮可以直接打开这个目录。
2. **类不符合条件**：必须 `public`、非抽象、有公开无参构造函数，并且实现了 `IBiliPlugin`（通常继承 `BiliPluginBase`）。
3. **`Id` 重复**：和内置插件或别的外部插件重名时，后注册的被忽略，主日志里有“插件xxx重复注册，已忽略”。
4. **加载出错**：日志里的“加载外部插件...失败:...”后面是异常信息，常见的有下面几种。

| 异常信息 | 原因 |
| --- | --- |
| 找不到文件或程序集 `xxx` | 插件依赖的 dll 没有放进同一个子文件夹 |
| 提示已加载同名程序集、或程序集版本不符（`FileLoadException`） | 插件文件夹里带了和宿主版本不同的接口程序集、`LinePutScript` 或 VPet 的 dll。删掉它们，只保留插件自己的 dll |
| 找不到方法、类型加载失败 | 编译时引用的接口版本和 mod 里的不一致，换成对应版本重新编译 |
| 文件被占用、访问被拒绝 | 游戏正在运行，先关闭游戏再替换 dll |

5. **被用户关闭**：设置窗口“基本设置”页的插件列表里取消勾选后插件不启动，勾上即可。

## 插件启用了，但没有反应

- 没有登录直播间就不会有任何直播事件。确认 mod 已登录，并且主播正在开播。
- 订阅在 `OnStart` 里（`BiliPluginBase`）。如果自己实现 `IBiliPlugin`，要在 `Start` 里订阅。
- 事件类型必须和订阅的类型完全一致，总线不做继承匹配。
- 同一弹幕可能已被别的插件处理：处理器里先检查 `e.Handled`，再看优先级是不是排在了应该拦截它的插件后面。优先级表在 [events.md](events.md#处理器优先级)。
- 处理器里抛出的异常会被记录在主日志里（“事件xxx处理出错”），看一下有没有。

## 桌宠不说话

- 发布 `SpeakRequestEvent` 只是请求，由宿主的朗读队列排队朗读。队列有长度限制（用户在基本设置里设置），请求太多时不会全部朗读。
- 桌宠正在工作、睡觉或播放升级动画时只显示气泡，不会被打断。

## 异常：调用线程必须为 STA / 另一个线程拥有该对象

在直播事件处理器里直接创建或修改了 WPF 控件。直播事件在 B 站 WebSocket 线程触发，操作控件或桌宠要用 `Ui.Post(() => { ... })`，需要等结果时用 `Ui.Dispatcher.Invoke`。

## `Ui.Dispatcher` 是 null

只会在没有宿主的环境里发生（例如单元测试）。宿主启动时已经设置好，插件不要调用 `Ui.Init()`。

## 设置没有保存

- 设置只在用户点“确定”或“应用”后才写出。点“取消”不保存。
- 设置页的 `apply` 回调要把界面上的值写回插件字段，写文件由宿主调用 `SaveSettings` 完成。
- `SaveSettings` 只更新自己的节，不要新建 `LpsDocument` 替换，否则会丢掉别的插件的设置。
- 自己的节名要避开已被占用的设置节名，见 [events.md](events.md#内置插件)。

## 读设置得到 0 或空字符串

键不存在时 LinePutScript 返回类型默认值（0、false、空字符串）。判断 `section.Count == 0`（首次运行）和值是否有效，无效就保持字段上的默认值，不要把 0 当成用户的选择。

## 关闭再启用插件后行为不对

关闭时宿主丢弃插件实例，再次启用是全新实例。不要把状态放在静态字段里；`OnShutdown` 要停掉自己创建的线程、定时器，移除挂到主窗口上的控件。否则重新启用后会出现两份。

## 礼物金额对不上

- 事件里的价格是单价，总价是 `Price × GiftNum`，单位是 1/1000 元。
- 设置页和播报用的是“电池”（1 电池 = 100 内部单位 = 0.1 元）。
- 充电弹幕 `Rmb` 的单位是元，不是 1/1000 元。

## 没有验证的行为

mod 本体没有在所有环境下验证，下面这些外部插件相关的行为需要在实机上确认：

- VPet 加载 mod 时的代码检测对插件自带资源的处理：示例插件没有 XAML，带 XAML（BAML 资源）的外部插件是否被拦截没有验证。
- `SubPlugins` 在 `ModData/BiliVpet` 下，和设置、存档放在一起。VPet 的 MOD 存储目录是否随 Steam 云同步上传里面的 dll 没有验证。
- 接口程序集 `VPET.Plugin.BiliBiliTest.Interface.dll` 必须和 mod 的 `BiliBiliTest.dll` 一起放在 `plugin` 文件夹。
